🛠️ Meta Developer App & Firebase Integration Guide

Official Meta Instagram Graph API requirements and server-side Cloud Function configuration.

1

Register Meta Developer App: Go to Meta for Developers, create a "Business" or "Consumer" type app, and add the Instagram Graph API / Instagram Login product.

Requires scopes: instagram_basic and instagram_manage_insights.
2

Configure OAuth Redirect URI: In your Meta App Dashboard under Instagram > Basic Display or Instagram Login Settings, add your Firebase Cloud Function callback endpoint:

https://us-central1-YOUR_PROJECT_ID.cloudfunctions.net/instagramOAuthCallback
3

Account Requirement: The connected account must be an Instagram Professional Account (Creator or Business). Personal Instagram accounts do not have API permissions for media metrics or insights.

You can convert any Instagram account to Professional in Instagram App > Settings > Account Type > Switch to Professional Account (free).
4

Server-Side Secret Storage: Client secrets and long-lived access tokens are strictly managed in Firebase Cloud Functions and stored in the private collection instagramTokens/{userId} with zero client-read access.
